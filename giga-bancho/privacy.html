BEYTH STUDIO（以下「当方」）は、ギガ番長（以下「本アプリ」）における情報の取り扱いを以下の通り定めます。

1. 本アプリの目的

本アプリは、Wi-Fiを戻し忘れたまま動画やSNSを見続けてしまう事故に気づくための見張りアプリです。Android向けアプリでは、モバイル回線やAndroidが従量課金扱いにする接続で通信量が短時間に増えた場合に通知します。iPhone/iPadでは、現在の回線状態を表示し、AppleのScreen Time関連APIを使った見張り設定を端末内で扱います。ギガ番長は、iPhone/iPadでバイト単位の通信量増加を測定して通知するアプリではありません。

2. 取得しない情報

見張り機能は、以下の情報を収集、保存、外部送信しません。

  • 氏名、メールアドレス、電話番号などの個人情報
  • 位置情報
  • 通信内容、パケット内容
  • URL、DNS、閲覧履歴
  • アプリ別の通信履歴
  • アプリの利用履歴
  • SSID、BSSID
  • 連絡先、写真、ファイル

3. 端末内で利用する情報

本アプリは、次の情報を端末内で利用します。

共通

  • 現在の接続種別（Wi-Fi、モバイル通信、VPN、未接続など）
  • ユーザーが設定した通知の目安、次に知らせるまでの時間、通知設定、広告解除状態
  • 画面表示、通知判定、ユーザー設定の保存に必要なアプリ内設定

Android向けアプリで利用する情報

  • Androidが提供する接続状態（接続種別、インターネット到達性、従量課金扱いかどうかなど）
  • 端末全体のモバイル通信量、またはAndroidが従量課金扱いにする接続での通信量の合計値
  • 本アプリ自身のUID通信量（広告通信を検知値から差し引くため）
  • ユーザーが「通知しないアプリ」として選んだアプリのパッケージ名
  • 「通知しないアプリ」機能を使う場合、選択したアプリが現在前面にあるかどうか

iPhone/iPadで利用する情報

  • 端末が確認できる現在の回線状態
  • Screen Timeの許可状態
  • FamilyControls / ManagedSettingsでユーザーが選んだ見張り対象の選択情報

これらの情報は、通知判定、画面表示、ユーザー設定の保存、Screen Time見張り設定の反映のためだけに使います。

「通知しないアプリ」機能は任意です。初期状態では除外アプリはなく、すべてのアプリ利用中に通信量の見張り対象になります。この機能で利用するAndroidの使用状況アクセスは、選択したアプリの使用中だけ通知を抑えるために端末内で使い、アプリの利用履歴を保存または外部送信しません。

本アプリはAndroidのアプリデータバックアップを無効にし、Android 12以降のクラウドバックアップおよび端末間転送の対象からもアプリデータを除外します。

4. 外部送信について

本アプリ独自の解析SDK、クラッシュ解析SDKは組み込みません。アカウント登録も不要です。

Android向けアプリにはGoogle Mobile Ads SDK（AdMob）による下部バナー広告があります。広告配信のため、Googleの広告SDKが広告表示に必要な通信を行い、広告配信、分析、不正防止のためにIPアドレス、アプリ操作情報、診断情報、広告IDやapp set IDなどのデバイス識別子を収集・共有する場合があります。通信は暗号化されます。

2026年6月3日時点のiOS向けアプリには、第三者広告SDKを組み込んでいません。Screen Timeの見張り設定は、Appleが提供するFamilyControls / ManagedSettingsなどの仕組みを使って端末内で扱います。

5. ネットワーク操作について

本アプリは、Wi-Fiやモバイル通信の接続先をアプリが変更したり、通信を制御したりしません。VPN、パケット解析、通信内容の検査も行いません。Android向けアプリでは、通知や画面からAndroidの設定画面を開く場合がありますが、切替や自動接続オフはユーザー自身が判断します。

6. ローカルデータの削除

本アプリをアンインストールすると、端末内に保存された設定は削除されます。当方が運営するサーバー上に保存されるユーザーデータはありません。広告解除などの購入状態は、App StoreまたはGoogle Playの購入履歴に基づいて復元されます。
